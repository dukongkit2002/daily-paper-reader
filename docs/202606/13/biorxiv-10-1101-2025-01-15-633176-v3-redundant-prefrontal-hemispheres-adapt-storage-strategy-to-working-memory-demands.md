## 摘要
前额叶半球必须动态协调以维持视觉空间的统一表征。最近，提出了两种使用不同存储策略的对立理论：一种是高容量的专门化架构，每个半球控制对侧行为；另一种是故障安全的冗余架构，两个半球共同引导整个视觉空间的行为。我们分析了三只猕猴在执行视觉空间工作记忆任务时的双侧前额叶皮层记录。两个半球同样能预测行为不精确性，解码误差在半球之间相关性弱，序列依赖性保持在半球内局部，表明一种冗余的、弱耦合的组织结构。吸引子网络模拟显示，当任务需求低于记忆容量时，冗余提高了精度；而在更具挑战性的任务中，弱的半球间耦合通过允许半球专门化增加了容量。这些预测模式在人类和猕猴数据中得到了验证，调和了之前的发现，并揭示了一种灵活的半球间架构，能够适应不同的认知需求。

## Abstract
The prefrontal hemispheres must coordinate dynamically to maintain a unified representation of visual space. Recently, two opposing theories using distinct storage strategies have been proposed: A high-capacity specialized architecture, where each hemisphere governs contralateral behavior, and a fail-safe redundant one, where both hemispheres jointly guide behavior across the visual space. Here, we analyzed simultaneous bilateral prefrontal cortex recordings from three macaque monkeys performing a visuo-spatial working memory task. Both hemispheres equally predicted behavioral imprecision, decoding errors were weakly correlated between hemispheres, and serial dependence remained local within hemispheres, suggesting a redundant, weakly coupled organization. Attractor network simulations showed that redundancy improved precision when task demands were below memory capacity, while weak interhemispheric coupling increased capacity in more demanding tasks by allowing hemispheric specialization. These predicted patterns were validated in human and monkey data, reconciling previous findings and revealing a versatile interhemispheric architecture that adapts to varying cognitive demands.
