## 摘要
目标导向的导航需要对朝向预期结果的进度进行内部估计，然而大脑如何构建和表示这种信号仍不清楚。在这里，我们设计了一个具有几何上不同路径的多路线导航范式，并在小鼠执行目标导向的路线选择行为时，对内侧前额叶皮层（mPFC）活动进行了成像。我们发现，相当大一部分mPFC神经元在沿着标准化的起点到目标轴的固定位置放电，与路径几何、奔跑方向和任务情境无关。在群体水平上，mPFC活动能够可靠地解码空间进度，但携带的关于路径身份的信息极少。这种进度编码随着任务熟悉度而出现，并需要来自海马CA1区的输入。失活mPFC或CA1到mPFC的投射并不会破坏已习得的路径偏好，但会损害训练有素的小鼠的导航流畅性。这些发现揭示了一种海马-前额叶机制，用于在目标导向的导航事件中表示抽象的、跨情境泛化的空间进度，支持跨可变路线的流畅导航。

## Abstract
Goal-directed navigation requires an internal estimate of progress toward a desired outcome, yet how the brain constructs and represents such a signal remains unclear. Here, we designed a multi-route navigation paradigm with geometrically distinct paths and imaged medial prefrontal cortex (mPFC) activity as mice performed goal-directed route choice behavior. We found that a substantial fraction of mPFC neurons fired at consistent positions along a normalized start-to-goal axis, independent of path geometry, running direction, and task context. At the ensemble level, mPFC activity reliably decoded spatial progress but carried minimal information about path identity. This progress code emerged with task familiarity and required input from the hippocampal CA1. Inactivation of either mPFC or CA1[-&gt;]mPFC projection did not disrupt learned path preference but impaired navigational fluency in trained mice. These findings reveal a hippocampal-prefrontal mechanism for representing abstract, context-generalized spatial progress within a goal-directed navigational episode, supporting fluent navigation across variable routes.

### 2. 方法论

*   **核心思想**：
    *   通过设计一个包含多条几何形状各异（长短、曲直）路径的“多路线选择范式”，将动物的空间导航行为中的“物理路径”和“任务进度”这两个变量解耦。
    *   通过将不同路径上的物理轨迹线性化并归一化到同一“空间进度”轴（0% 到 100%），比较 mPFC 神经元活动是与绝对空间位置、路径几何、奔跑时间、目标距离还是与“标准化空间进度”更相关。

*   **关键技术细节**：
    *   **行为范式**：一个定制的多路线迷宫，包含两条曲线（长、短）、一条折线和一条直线共四条路径，连接两个给水口。小鼠需在两口之间往返以获取水奖励。
    *   **钙成像**：在 mPFC 兴奋性神经元中表达 GCaMP6s，使用微型荧光显微镜在自由活动的小鼠中记录神经活动。
    *   **轨迹线性化与归一化**：
        1.  通过行为追踪获取小鼠的二维运动轨迹。
        2.  对每条路径，生成一条标准轨迹。
        3.  将每个试次的运动轨迹投影到对应路径的标准轨迹上，并根据累计路径长度将物理位置归一化为 0% (起点) 到 100% (终点) 的“空间进度”轴。
    *   **化学遗传学抑制**：通过表达抑制性 DREADD 受体 (hM4Di) 并结合配体 CNO，实现对 mPFC 或 CA1→mPFC 投射的选择性可逆抑制。
    *   **神经元分析**：
        *   **空间进度细胞鉴定**：筛选在单个路径内表现出位置细胞样调谐，且在不同路径的相似空间进度阶段表现出峰值放电的神经元。
        *   **响应抖动分析**：计算神经元在不同试次中峰值放电位置的标准差，以量化其在时间对齐、目标距离对齐和空间进度对齐三种条件下的发放一致性。
    *   **群体解码分析**：
        *   使用支持向量机解码器，从神经元群体活动中解码动物的空间进度。
        *   使用朴素贝叶斯分类器，解码动物的路径身份和奔跑方向。

### 6. 主要结论与发现

1.  **mPFC 的功能是支持导航流畅性而非路径偏好**：失活 mPFC 或 CA1→mPFC投射不会改变小鼠对最短路径的偏好，但会减少完成的试次，增加停顿和选择时间，损害导航效率。
2.  **mPFC 神经元编码抽象的“空间进度”**：发现了一类“空间进度细胞”，它们在标准化的起点-终点轴上固定位置稳定放电，其活动由“进度”本身最好地解释，而非流逝的时间、到目标的距离或具体的路径几何。
3.  **训练促使进度编码的形成和泛化**：该编码显著依赖于任务熟练度，在未经训练的小鼠中不存在。一旦形成，它可以泛化到不同的奔跑方向、路径形状甚至全新的任务场景中。
4.  **mPFC 群体活动序贯表征进度而非路径**：mPFC 群体的神经流形形成了一个环状结构，序贯地表征了空间进度；解码模型可以准确判断进度，但无法区分路径。
5.  **海马 CA1 输入是 mPFC 进度编码的来源**：抑制 CA1→mPFC 投射会破坏大约一半的空间进度细胞的身份，打乱群体活动的序贯结构，并降低空间进度的解码准确率。这表明 mPFC 的抽象进度编码依赖于海马体提供的具体空间信息。

### 7. 优点

*   **创新的行为范式**：巧妙地设计了多路径迷宫，将“进度”从具体的“路径”变量中分离出来，这是揭示抽象认知编码的关键。
*   **严谨的分析方法**：通过将神经活动与时间、距离和进度三种变量对齐并对比，令人信服地证明了“空间进度”才是驱动 mPFC 神经元活动的核心变量。
*   **多层次的证据链**：从行为学功能（化学遗传学）到单细胞表征（空间进度细胞）、群体编码（解码、流形）再到环路机制（CA1→mPFC 投射），构建了一个完整且一致的证据闭环。
*   **强大的泛化性验证**：通过引入“无选择任务”和“梯形T迷宫”，有力地证明了空间进度编码是一个跨情境的广义机制，提升了研究发现的重要性。

### 8. 不足与局限

*   **仅使用雄性小鼠**：所有实验均采用成年雄性小鼠，未能评估这一发现是否在雌性小鼠上得到重复，限制了结论在性别层面的普适性。
*   **奖励类型单一**：行为动机仅为水奖励，未探索其他类型奖励（如食物、社交）驱动的导航中是否存在相同的进度编码。
*   **mPFC 功能解读的广度**：结论强调 mPFC 失活不影响路径偏好，但这可能受任务特质影响。论文也指出，在需要工作记忆而非长期记忆、且错误惩罚更严苛的任务中（如经典的T迷宫交替任务），mPFC 的功能可能不同。该研究的任务成本主要在于能量和时间消耗。
*   **成像范围与细胞类型**：研究主要使用 CaMKIIα 启动子靶向兴奋性神经元，未探讨抑制性神经元对进度编码的贡献。微型显微镜的单视场成像可能仅覆盖了部分 mPFC 亚区。
