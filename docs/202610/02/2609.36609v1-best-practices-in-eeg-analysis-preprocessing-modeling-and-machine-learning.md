## 摘要
脑电图（EEG）分析需要在预处理、统计建模和机器学习中做出谨慎选择，因为EEG信号极易受到伪迹、容积传导、低信噪比以及显著个体间差异的影响。本章为现代脑电图分析提供实用且具有方法学意义的指南，涵盖EEG预处理、伪迹去除、滤波、坏导检测与插值、重参考、独立成分分析（ICA）以及同步EEG-fMRI记录的预处理。我们回顾了计算脑电图分析的主要方法，包括事件相关电位（ERPs）、时频分析、功能连接与有效连接、源定位、多变量解码、置换检验以及多重比较校正。随后，我们考察了用于EEG的机器学习方法，从基于特征的分类器到深度学习以及新兴的EEG基础模型，重点关注跨被试泛化、有限数据场景、数据泄漏、评估指标和公平基准测试。可重复性始终被视为核心要求，包括透明的预处理、BIDS-EEG数据组织、标准化衍生数据、原始数据保存以及FAIR数据实践。本章旨在为研究人员开发可靠、可解释且可重复的EEG分析和机器学习流程提供实用参考。

## Abstract
Electroencephalography (EEG) analysis requires careful choices in preprocessing, statistical modeling, and machine learning because EEG signals are highly susceptible to artifacts, volume conduction, low signal-to-noise ratio, and substantial inter-subject variability. This chapter provides a practical and methodological guide to modern EEG analysis, spanning EEG preprocessing, artifact removal, filtering, bad-channel detection and interpolation, re-referencing, independent component analysis (ICA), and preprocessing of simultaneous EEG-fMRI recordings. We review major approaches for computational EEG analysis, including event-related potentials (ERPs), time-frequency analysis, functional and effective connectivity, source localization, multivariate decoding, permutation testing, and multiple-comparison correction. We then examine machine-learning methods for EEG, from feature-based classifiers to deep learning and emerging EEG foundation models, with emphasis on cross-subject generalization, limited-data regimes, data leakage, evaluation metrics, and fair benchmarking. Reproducibility is treated as a core requirement throughout, including transparent preprocessing, BIDS-EEG data organization, standardized derivatives, preservation of raw data, and FAIR data practices. The chapter is intended as a practical reference for researchers developing reliable, interpretable, and reproducible EEG analysis and machine-learning pipelines.

## 2. 论文提出的方法论

本章没有提出新的算法，而是**系统归纳与推荐最佳实践**，核心内容如下：

### 2.1 预处理方法论

- **伪迹识别与分类**：
  - 生理伪迹：眼动/眨眼（EOG，100–200 μV，delta/theta 频段）、肌电（EMG，20–300 Hz）、心电/脉搏（ECG/BCG）、呼吸与出汗（0–0.5 Hz 漂移）、头动等。
  - 非生理伪迹：工频干扰（50/60 Hz）、电极弹跳、线缆移动、环境电磁干扰等。
- **滤波建议**：
  - 高通滤波：推荐 **0.1–1 Hz**，尤其 ERP 研究建议 0.1 Hz 以防低频成分失真；过高截止频率会产生伪效应和潜伏期偏移。
  - 低通滤波：认知研究常用 **30–40 Hz**；分析 gamma 或高频振荡时可提高至 80 Hz 或不滤波。
  - 工频陷波：可用窄带 Butterworth 陷波、CleanLine 多锥回归或频谱插值。
  - 抗混叠：降采样前必须低通至新 Nyquist 频率，推荐线性相位 FIR 零相位滤波（filtfilt）。
- **坏道检测与插值**：
  - 自动指标：频谱偏差、平线检测（flatline > 5 s）、方差异常、邻道相关性阈值（如 r < 0.8）。
  - 修复方式：排除或插值（球面样条/近邻平均），建议在预处理早期处理坏道并进行可视化确认。
- **参考方案**：
  - 高密度 EEG 推荐**共同平均参考**；REST 提供“无穷远零参考”的模型化替代；Laplacian/CSD 可提高空间特异性但放大噪声；单电极参考不推荐。
- **伪迹校正**：
  - **ICA** 是核心方法，包含 Infomax、Extended Infomax、Picard、FastICA、SOBI、AMICA 等；应用前需高通信滤波、去坏道、处理数据秩（平均参考降 1）；用 ICLabel 辅助分类伪迹成分。
  - 其他方法：回归法、SSP/SSS、ASR（自动化瞬态伪迹抑制）、GEDAI（基于前向模型的无监督去伪迹）。
  - 同步 EEG-fMRI：需先移除梯度伪迹（AAS）和脉搏伪迹（ECG 模板法），再执行标准处理。

### 2.2 计算建模方法论

- **ERP 分析**：锁时平均、基线校正；梳理 P50、P100/N1、P200、N200、P300（P3a/P3b）、N400、P600 等成分的潜伏期、极性与认知含义。
- **时频分析**：FFT、Welch、STFT、小波（Morlet）、Hilbert、多锥（DPSS）等方法；按 delta、theta、alpha、beta、gamma 频段解释功能。
- **连接分析**：
  - 功能连接：相关、相干、PLV、PLI（抗容积传导）。
  - 有效连接：Granger 因果、DTF；强调容积传导和场扩散对解释的影响。
- **源定位**：前向模型 + 逆问题求解，强调电极坐标和头部电导模型的重要性。
- **多变量分析/解码**：SVM/LDA 分类、时间分辨解码、表征相似性分析（RSA）、时间泛化、状态空间模型、反向编码模型（IEM）。

### 2.3 机器学习方法论

- **经典 ML**：ICA/PCA 降维 + LDA/QDA/SVM/XGBoost/Random Forest。
- **深度学习**：
  - CNN：EEGNet（紧凑型/深度可分离卷积）、SPaRCNet（临床 ICU EEG）。
  - Transformer：ST-Transformer、EEGFormer。
  - GNN：DGCNN 等，将电极视为图节点。
- **自监督/基础模型**：
  - 对比学习：BENDR、BIOT。
  - 掩码重建：CSBrain、CBraMod、S4 系列（结构化状态空间）。
- **评估策略**：强调跨被试留一法（leave-one-subject-out）、按 session/block 划分、防数据泄漏、嵌套交叉验证、标准化基准 MOABB、除 accuracy 外应报告 balanced accuracy / AUC / kappa / F1。

### 2.4 可重复性与数据组织

- 采用 **BIDS-EEG** 标准，区分 raw 与 derivatives；保留 ICA 权重、预处理参数、软件版本、随机种子；遵循 **FAIR** 原则。

## 6. 论文的主要结论与发现

- **预处理**：应优先采用保守滤波（0.1 Hz 高通、30–40 Hz 低通）、共同平均参考、ICA 结合 ICLabel 自动化分类；ASR/GEDAI 可作为补充；同步 EEG-fMRI 需先去除梯度和脉搏伪迹。
- **计算建模**：ERP 提供高时间分辨率但空间特异性有限；时频分析能捕捉非相位锁定振荡；连接分析易受容积传导影响，PLI、虚部相干等能减轻偏差；多变量解码可揭示分布式神经表征。
- **机器学习**：紧凑型深度模型（如 EEGNet）凭借强领域归纳偏置，在小样本任务上常与大规模基础模型性能相当；基础模型的优势取决于数据规模、跨数据集对齐和去噪能力。
- **统计与可重复性**：必须使用置换检验、聚类置换和 FDR/Bonferroni 等校正；采用 BIDS-EEG、透明报告、保留原始数据与标准化衍生数据是可靠推断的前提。
- **总体主张**：可重复性不是附属步骤，而是贯穿所有分析阶段的**基础性原则**。
