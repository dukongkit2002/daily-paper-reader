## 摘要
客观评估学习仍然是教育中的一个根本挑战。脑电图（EEG）为知识获取的神经相关物（包括认知熟悉度）提供了一个直接、非侵入性的窗口。本研究对十五种机器学习（ML）和深度学习（DL）模型进行了基准测试，用于跨两个认知领域的基于 EEG 的熟悉度预测：面孔（事实性知识）和数学方程（概念性知识）。使用来自 23 名参与者的连续 EEG 数据，我们提取了六个频段的频谱特征（功率谱密度）。我们表明，虽然标准的分层交叉验证由于相邻 epoch 之间的时间泄漏而产生人为的高分类性能（使用 CNN 时 F1 分数高达 0.9853），但严格的试验独立验证（分组 K 折）将峰值性能降至 0.6038 F1 分数（使用 CNN），这在统计学上仍显著高于 25% 的随机水平。这凸显了试验独立评估对于避免高估模型泛化能力的至关重要性。此外，特征重要性和 SHAP 分析表明，颞叶和额叶的 Gamma 和 Beta 振荡是熟悉度最关键的生物标志物。这项工作为教育技术中基于 EEG 的认知监测建立了一个现实的基准。

## Abstract
Objective assessment of learning remains a fundamental challenge in education. Electroencephalography (EEG) provides a direct, non-invasive window into the neural correlates of knowledge acquisition, including cognitive familiarity. This study benchmarks fifteen machine learning (ML) and deep learning (DL) models for EEG-based familiarity prediction across two cognitive domains: faces (factual knowledge) and mathematical equations (conceptual knowledge). Using continuous EEG data from 23 participants, we extract spectral features (Power Spectral Density) across six frequency bands. We show that while standard stratified cross-validation yields artificially high classification performance (up to 0.9853 F1-score using CNN) due to temporal leakage across neighboring epochs, a rigorous trial-independent validation (Group K-Fold) drops the peak performance to 0.6038 F1-score (using CNN), which is still statistically significant above the 25% chance level. This highlights the critical necessity of trial-independent evaluation to avoid overestimating model generalizability. Furthermore, feature importance and SHAP analysis reveal that temporal and frontal Gamma and Beta oscillations are the most critical biomarkers for familiarity. This work establishes a realistic benchmark for EEG-based cognitive monitoring in educational technologies.

### 2. 论文提出的方法论

- **核心思想**：从连续 EEG 中提取频谱特征（功率谱密度，PSD），训练分类器区分四类状态：熟悉面孔、不熟悉面孔、熟悉方程、不熟悉方程。
- **数据采集与预处理流程**：
  - 23 名健康被试（12 女 11 男，年龄 20–30，STEM 背景），14 通道 EEG（Fp1, Fp2, F3, F4, F7, F8, C3, C4, T3, T4, P3, P4, O1, O2），256 Hz 采样。
  - 刺激：40 张熟悉 + 40 张不熟悉面孔 / 方程，每张显示 2.5 s，间隔 1.5 s。预实验问卷确认熟悉度真值。
  - 预处理：1–100 Hz 带通滤波、通道定位、基线去除、连续与分段伪迹剔除（约 3.2% 试次）、ICA 去除眼动/肌电成分（平均 2.1 个 ICs）。
- **特征提取**：
  - 滑动窗口 128 样本（0.5 s），87.5% 重叠；Welch 方法（段长 64 样本，50% 重叠）计算 PSD。
  - 六个频段：Delta（1–4 Hz）、Theta（4–8 Hz）、Alpha（8–13 Hz）、Beta（13–30 Hz）、Low Gamma（30–50 Hz）、High Gamma（50–100 Hz）。
  - 每个 epoch 得到 84 维特征（14 通道 × 6 频段）。
- **验证协议**：
  - **Stratified K-Fold（有泄漏）**：随机打乱 epoch 做 5 折，相邻窗口来自同一 trial 可能同时出现在训练/测试集，导致时间泄漏。
  - **Group K-Fold（试验独立）**：按唯一 trial block ID 分组，同一 trial 的 epoch 只在同一折，有效防止时间泄漏。
- **模型集合**：共 15 种模型，包括 Logistic Regression、Ridge、Linear SVM、RBF SVM、KNN、GaussianNB、Decision Tree、Random Forest、Extra Trees、Gradient Boosting、XGBoost、HistGradient Boosting（仅域隔离任务），以及 DNN、CNN、LSTM 三种深度模型。
- **深度学习配置**：
  - DNN：输入 84 维，两个隐藏层（32、16 神经元，ReLU，Dropout 0.5），softmax 输出，Adam（lr=0.001），早停 patience=15。
  - CNN/LSTM：将 84 维向量重塑为 14×6 的“空间-频谱伪序列”作为输入（作者指出该伪序列缺乏真实物理连续性，是概念性局限）。

- **数据集**：自采集 EEG 数据集，共 3960 个样本：

### 6. 论文的主要结论与发现

- **验证协议影响巨大**：Stratified K-Fold 下 CNN 最高 F1 = 0.9853，DNN 0.9433；但 Group K-Fold 下峰值降至 CNN 0.6038，Gradient Boosting 0.5510。时间泄漏显著高估性能。
- **真实性能仍显著高于随机**：Group K-Fold 结果显著高于 25% 理论随机水平（以及经验基线 26.72%），证明模型学到了真实的熟悉度模式。
- **域隔离分类**：LOGO 下，域分类平均召回率 0.9491（CNN）；方程内熟悉度 0.8670（CNN）；面孔内熟悉度 0.8992（HistGradient Boosting）。置换检验显示三项任务均显著（Bonferroni 校正后 p ≤ 0.0360）。
- **神经生理标志物**：随机森林特征重要性显示 High Gamma（32.2%）、Low Gamma（26.2%）、Beta（15.8%）最重要；关键通道为 T3、P3、F7、T4。SHAP 表明 T4、F8、F7 的 Gamma/Beta 功率增高驱动“熟悉”预测，符合主动记忆检索的神经机制。
- **与单变量检验的对比**：单变量 Welch t 检验 + FDR 未发现熟悉度相关的单个频段特征显著，而多变量分类器能捕捉分布式空间-频谱联合模式，说明熟悉度表征是复杂的多元模式。

### 7. 优点

- **方法论严谨**：明确区分并对比有泄漏与无泄漏验证协议，指出领域内普遍存在的性能高估问题，为 EEG 分类研究树立了良好实践。
- **模型全面**：覆盖经典 ML、集成学习与 DL，提供系统性基准。
- **统计与可解释性并重**：不仅报告 F1，还进行 trial 级统计检验、置换检验、FDR/Bonferroni 校正；同时用随机森林和 SHAP 揭示关键频段与脑区，增强结果可解释性。
- **任务设计合理**：同时包含面孔（事实知识）与方程（概念知识）两类刺激，区分域分类与域内熟悉度分类，避免域信息混淆熟悉度信号。
- **类别不平衡处理**：使用类别加权和加权 F1，评估更公平。

### 8. 不足与局限

- **样本规模与同质性**：仅 23 名被试，均为 STEM 背景，年龄集中，限制了结论的泛化性。
- **跨被试泄漏风险**：未保留被试 ID，只能做 trial 级 Group K-Fold，无法排除同一被试的 trial 出现在训练/测试集；对于域隔离任务（面孔仅 13 块），该风险更突出。
- **LOGO 指标不稳定**：域隔离任务的 LOGO 平均召回率标准差很大（如方程内 CNN 0.8670 ± 0.2392），结果易受个别噪声块影响。
- **置换检验的代表性**：因算力限制，显著性检验仅用 HistGradient Boosting，未对 CNN 等高性能模型单独验证，显著性界限的架构特异性不足。
- **频谱分辨率限制**：Welch 段长 64 样本在 256 Hz 下频率分辨率约 4 Hz，难以精确分离 Delta（1–4 Hz）等窄带。
- **手动预处理主观性**：ICA 选择和伪迹剔除依赖人工判断，可能引入偏差，未来可用 ICLabel 等自动化工具。
- **伪序列输入问题**：CNN/LSTM 将 14×6 特征当作空间-频谱序列，缺乏真实物理连续性，限制了深度架构的优势。
- **特征类型单一**：仅使用频谱功率特征，未结合时域 ERP 成分（如 N170、N400/P300），可能遗漏重要信息。
